# Referências dos dados ilustrativos
Os pesos individuais foram criados para o jogo; não representam medições reais, médias estatísticas nem orientação de manejo. As referências abaixo dão contexto às faixas usadas. Sexo, idade, população e espécie científica influenciam o peso. Cada valor individual é diferente para evitar empates no exercício SQL.

| Rótulo na tabela | Faixa usada no jogo (kg) | Contexto |
|---|---:|---|
| Leão | 125–245 | Faixa ilustrativa para adultos |
| Girafa | 600–1250 | Adultos de diferentes portes |
| Elefante | 2800–5900 | Adultos africanos de diferentes portes |
| Zebra | 219,5–400 | Um jovem de dois anos e outros indivíduos |
| Tigre | 90–290 | Faixa adulta ampla, conforme população |
| Macaco | 2,1–9 | Jovem e adultos, modelo ilustrativo de bugios |
| Arara | 0,85–1,25 | Grupo ilustrativo de araras de grande porte |
| Pinguim | 2,3–4,6 | Modelo de pinguim-africano |
| Jacaré | 12–38 | Modelo de jacaré-de-óculos |
| Tartaruga | 105–220 | Modelo de tartarugas gigantes terrestres de Galápagos |

As idades são fictícias em anos inteiros. Os três mais novos têm 1, 2 e 3 anos; os três mais velhos são tartarugas de 73, 87 e 96 anos. A referência de Galápagos registra indivíduos acima de 100 anos. Não há empates nessas posições.
